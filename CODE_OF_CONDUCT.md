# Code of conduct

Be respectful. Disagree about implementation, not about a person's worth.

This project handles sacred text. Do not mock contributors' faith or lack of faith. Do not use this repository to harass, evangelize coercively, or pick fights across traditions.

Unacceptable: harassment, hate, doxxing, sexualized attention, or dumping copyrighted Bible text into issues and pull requests.

Report conduct issues privately to the repository owner via GitHub. For this personal public repo, the owner is @ChristFollower873461.

Consequences may include a warning, content removal, or a ban from the project.
